O Jujutsu Academy é um jogo de terminal que combina as funcionalidades e atividade de RPGs, Jujutsu Kaisen, Emojis e If/Elses simples para criar uma jornada curta mas divertida.

***Última versão:*** $\color{green}{\textsf{jujutsu-academy-latest.py}}$
- Uma versão sem bugs, otimizada e com gameplay melhor

***Primeira versão:*** $\color{red}{\textsf{jujutsu-academy-old.py}}$
- A primeira e mais antiga versão do jogo, não recomendável (possui bugs e uma gameplay pior)

# 1. ✍ FUNCIONALIDADES: 

***1: Treinamentos & Missões***
- Siga a sua jornada de RPG de texto treinando! Comece se alistando na Academia Jujutsu, onde você receberá um teste de dar 10 socos até despertar sua energia amaldiçoada. Após isso, você será um feiticeiro de Grau 4, e poderá finalmente começar a sua experiência de verdade, podendo treinar com Satoru Gojou para ganhar experiência de combate, completar missões para ganhar dinheiro ou melhorar seu arsenal usando todo o seu esforço para aumentar seu arsenal

***2: Lojas e Compras***
- Ao treinar e completar missões, você receberá experiência e dinheiro, respectivamente. Você pode usar esses valores para comprar novas técnicas, ou então gastar o seu dinheiro em armas amaldiçoadas que farão seu personagem se tornar ainda mais forte!

***3: Status e RankUp***
- Ao apertar o botão de status (geralmente 5 nos menus iniciais), as estatísticas do seu personagem serão reveladas, mostrando sua quantia de Experiência, Dinheiro, Maestria, Técnicas Obtidas e Armas no Arsenal numa lista fácil de ler, ajudando-o a planejar melhor.
- Para subir de Grau é bem simples: apenas maximize tudo do seu menu atual. Começando no menu de Grau 4 (nomeado como "O Começo"), você simplesmente deverá treinar e participar em missões até poder aprender todas as técnicas e ter comprado todas as armas.

# 2. 👨‍💻 INSTALAÇÃO E PRÉ-REQUISITOS:

***1. Python***

- O projeto roda completamente no arquivo *.py, então caso queira rodar e jogá-lo, será necessário uma instalação de Python (preferivelmente a mais recente) no seu computador.
- Você pode encontrar os arquivos de instalação [aqui](https://www.python.org/downloads/), e um guia de instalação da wiki oficial [aqui](https://wiki.python.org/moin/BeginnersGuide(2f)Download.html)

***2. VSCode / Algum editor de código (opcional, extremamente recomendado)***

- Ao baixar quaisquer versões do jujutsu-academy, você poderá simplesmente abrir e rodá-lo pelo terminal (nota: lembre-se de usar cd para ir para o diretório de onde o arquivo estiver baixado, e usar o comando 'python nomedoarquivobaixado.py* para realmente rodá-lo
- Entretanto, é extremamente recomendado usar algum IDE (Editor de código), como o VSCode, para um suporte de Emojis e visualização mais simples. Você pode achar o download do VSCode [aqui](https://code.visualstudio.com/download?_exp_download=fb315fc982), caso baixe o VSCode mesmo, lembre-se de baixar a extensão do Python dentro dele, você pode achar um guia de como fazer isso [aqui](https://codigofacil.com.br/instalando-python-no-vscode/)

# 3. ❓ EXEMPLOS DE USO/DICAS:

- O projeto é extremamente simples, e bem fácil de acompanhar. Não há comandos específicos ou difíceis de entender como funciona, já que a maioria do controle do jogo simplesmente funciona escolhendo o número correspondente à alguma ação. Caso utilize algum editor de código, certifique-se de que a janela do terminal seja grande o bastante para visualizar todo o texto e os emojis.
